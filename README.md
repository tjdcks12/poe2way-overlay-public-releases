# poe2way overlay

Public Windows x64 installers for poe2way overlay.

- Latest installer: https://www.poe2way.com/overlay/download
- Releases: https://github.com/tjdcks12/poe2way-overlay-public-releases/releases
- Public normal edition only. The other edition has a separate repository.
- Each release includes the installer, updater signature, SHA-256 checksums, version metadata, and release notes.
- No application source, signing keys, user data, or runtime captures are published here.

App update checks use the existing poe2way website. No GitHub token or additional user software is required.
